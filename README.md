Проект по оптимизации инвестиционного портфеля с использованием ML и учета транзакционных издержек

##  Задачи проекта
1. Исследовать, какие технические признаки (моментум, волатильность, объем) статистически значимы для прогноза доходности.
2. Сравнить эффективность разных моделей (линейные, ансамбли) на финансовых временных рядах.
3. Реализовать многокритериальную оптимизацию: максимизация доходности при минимизации риска и издержек.
4. Применить байесовский подход для принятия решений в условиях неопределённости.


##  План работы
1. Данные - скачать данные, почистить, рассчитать базовые признаки (доходность, объем) (res: processed_data.csv)
2. Статистика - корреляционный анализ, отбор признаков, проверка стационарности (res: список значимых факторов)
3. ML - обучить 2-3 модели, сравнить по метрикам (MAE, RMSE), выбрать лучшую (res: файл с прогнозами predictions.csv)
4. Оптимизация - реализовать целевую функцию (доходность - риск - издержки), запустить решатель (res: веса портфеля weights.csv)
5. Бэктест - прогнать стратегию на тестовой выборке, посчитать Sharpe, MDD, Turnover (res: )
